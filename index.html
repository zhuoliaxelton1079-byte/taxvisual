The explorable tax memo

A memo your client can test. Change a fact and the analysis recalculates — so the conversation is about the decision, not the arithmetic.

Read a sample memo How planning packages work

Facts
The client’s figures as defaults — basis, sale price, holding period, income — each one adjustable.
Issue
One plain-language question the memo answers.
Law
The governing rules, cited to the Code and regulations, with a diagram of the order they apply in.
Analysis
Figures in the text recalculate as the facts change, with a chart beside each step.
Sensitivity
Which facts move the answer, and the thresholds where the conclusion flips.
Conclusion
The recommendation and the conditions that would change it — plus a static PDF for the file.

We work alongside your preparer

TaxVisual does not prepare returns, so we never compete for your client. We make the work you have already done easier to explain.

Advisors whose clients need a preparer can ask us for a suggestion when they get in touch.

How an engagement works

  1. Send the case

    A short call to scope it. The return or the facts then come through a secure file portal — never by email.

  2. We build it

    Walkthrough, memo or visuals, with every figure traced to the return or to a cited rule. You review it before anything reaches your client.

  3. You deliver it

    Under your firm’s name: a link your client can open, and a PDF for the file.
