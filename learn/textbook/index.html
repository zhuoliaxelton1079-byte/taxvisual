The visualized tax guide

A guide book that draws the rules instead of describing them, with the tool that demonstrates each one sitting next to it.

To be built

Most tax writing explains a rule in a paragraph and leaves you to imagine what it does to a number. This guide is being written the other way round: each section opens with the picture — the bracket ledger, the inclusion curve, the cascade of limits — and the prose explains what you are already looking at.

Planned as a chapter per mechanism, each one pairing a written explanation with the interactive tool that demonstrates it, so a reader can move between reading the rule and testing it on a figure of their own. Nothing is published yet, and no timetable is set.

Tell us which chapter you would want first

In the meantime

The interactive tools are the part of this that already exists. Each one takes a single rule and makes it movable, and each documents its own model and sources — which is the format the guide will be built around.
