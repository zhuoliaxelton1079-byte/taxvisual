Methodology

Methodology

Every TaxVisual tool is an educational simulation, not tax advice. These are the standards each tool is built to.

Sourcing

Each tool cites the rule set or rate schedule it uses (e.g. IRS brackets, a specific tax year) directly on its page, along with the date that data was last checked against the source.

Assumptions

Where a tool simplifies a real rule (a single filing status, a single tax year, no state-level rules), that simplification is stated on the tool's own page rather than left implicit.

Updates

Tax rules change annually. Tools are updated when a relevant rate schedule changes; the "last updated" date on each tool page reflects that, not just cosmetic edits. Changes are logged on Updates.

Accessibility

Tools support both light and dark display modes, are usable down to mobile widths, and use direct value labels rather than color alone to convey data.
